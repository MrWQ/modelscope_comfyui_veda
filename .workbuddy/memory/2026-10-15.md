# 2026-10-15 工作日志

## v2.3.14：启动前置硬门禁（修复"安装成功却启动必崩"循环）

### 背景（用户实测反馈）
用户在新容器 `dsw-2261335`（CPU-only 镜像，`nvidia-smi: not found`，`torch==2.3.1+cpu` 且**镜像 torch 确实缺少 `torch.library.custom_op`**）重跑 `install.sh`：
- auto 判定 `launch-only` → `preflight_launch` 探测到 torch 不兼容 → 抛 E701 → **auto 降级转安装段**（v2.3.13 行为，正确）
- 安装段完成（用户已 `y` 确认无 GPU 继续），`install_completed=true`
- 但 `phase8_launch` 仍**无条件 spawn** ComfyUI → 立即崩（exit 1，custom_op AttributeError）→ 等 120s + dump traceback → 报 E701
- 因 `install_completed=true`，**此后每次 `install.sh` 都 `launch-only → 崩溃`**，形成循环

诊断包 `diagnose_20261015_182954.tar.gz` 确认：`nvidia-smi: not found`、`torch==2.3.1+cpu`、`install_completed:true`。

### 根因
v2.3.13 的 `_torch_compat_ok` 只在 launch 预检与 install 验收（仅 WARN）用；auto 降级转安装后，`phase8_launch` 没有复跑任何环境判定，盲启必崩。

### 修复（lib/phases.py + setup_veda.py）
- 新增 `_launch_precheck(ctx)`：综合 venv 存在 + `_torch_compat_ok`（torch>=2.0/`custom_op`）+ `torch.cuda.is_available()`，返回 `(ok, reason)`。
- `phase8_launch(ctx, strict=True)` 进入即 `_launch_precheck`：
  - `strict=True`（`--mode launch`/`--only p8`）环境不满足 → 直接 `raise E701(reason)`，**绝不 spawn 必崩进程/不等 120s/不 dump traceback**。
  - `strict=False`（auto/install 顺带启动）环境不满足 → **跳过启动**（`log.warn` + `ctx.launch_skipped_reason` + `launch_ready=None`），安装已完成不崩不谎报。
- 驱动层：`--mode install`/auto 降级 → `phase8_launch(ctx, strict=False)`；`--mode launch`/`--only p8` → `strict=True`。
- `final_summary`：据 `launch_skipped_reason` 明确"未启动（环境不满足运行条件）"并指引换 GPU 镜像后 `run/start.sh` 启动。
- `_torch_compat_ok` 探针显式 `import torch.library`，防子模块未自动导入误判。

### 验证
- py_compile 全过；`test_v2310.py` 由 46 → **57 项全绿**：新增 [11] `phase8_launch` 启动前置门禁（strict 抛 E701 且 Popen 未调用 / best-effort 跳过不 spawn / 环境满足正常 spawn）、[12] `_launch_precheck` 四环境判定、final_summary 跳过诚实分支。
- 文档（设计文档/问题排错/使用说明/README/setup_veda.py）升 v2.3.14。

### 实测结论对用户
该 CPU-only 容器**无法运行 Veda**（无 GPU + torch 不兼容），必须换「带 NVIDIA GPU 且 torch>=2.0」镜像。换镜像后直接 `bash run/start.sh` 即可（资产已在 `install_completed=true` 实例中，无需重装）。`install.sh`（auto）现在会**正常装完资产并退出 0**，提示换镜像，不再崩溃循环。
