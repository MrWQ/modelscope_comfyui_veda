# Veda-on-ComfyUI 一键脚本 · 使用说明

本说明面向**直接使用脚本部署 Veda-on-ComfyUI（MiniMax-H3 加速节点）**的用户。设计原理、决策与可复现性见 [设计文档](Veda一键脚本设计文档.md)；出错时见 [问题排错](问题排错.md)。

> 版本对应：本脚本实现对齐设计文档 **v2.3.7**（含首次魔搭实例实测反馈修复：模型下载落点 / hf 兜底源链 / 阶段级快速跳过 / `--only` 单环节执行）。

---

## 1. 这是什么

一个跨平台（Linux / Windows / macOS 实验性）的一键驱动，用于在**魔搭社区（ModelScope）免费 Notebook** 等环境部署 **Veda-on-ComfyUI**——MiniMax-H3 视频扩散模型的官方加速节点（学习型稀疏注意力，约 3× 提速），并自动拉起 ComfyUI。

设计目标（详见设计文档）：
- **多平台**：同一套代码适配 Linux / Windows / macOS；
- **持久化免重装**：默认部署到魔搭 `/mnt/workspace`（100GB，关机保留）；
- **安装 / 启动自动分流**：同一条命令自动判断——首次（持久盘尚无安装）自动安装+启动；已安装（含重开实例，挂载同一持久盘）自动**仅启动**（跳过安装段，秒级进入）；
- **全自动**：默认零交互，选档/源链/降级全自动；
- **优先魔搭能力**：模型权重优先走 `modelscope` 官方 CLI 下载；
- **结构化日志 + 诊断包**：每个动作写 JSONL 日志，失败时自动打包诊断信息。

## 2. 环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Linux（推荐，魔搭 Notebook 即此）/ Windows 10+ / macOS（实验性，Apple Silicon，走 MLX 后端） |
| Python | **3.10 – 3.12**（3.13 未验证） |
| GPU | NVIDIA，计算能力 **≥ SM80（如 A10 / A100 / 30/40 系）**；纯 CPU 模式不可用 |
| 显存 | 见 §5 档位；A10 24GB 可跑 `standard` |
| 磁盘（魔搭） | 持久盘 `/mnt/workspace` ≥ 约 **46GB**（`standard` 档：模型 ~42GB + ComfyUI/venv ~3–4GB）；缓存默认重定向到本地盘 `/root/.cache` 以避开峰值爆盘 |
| 网络 | 可访问 `modelscope.cn`；GitHub 经国内代理（`gh-proxy.com` 等）兜底；魔搭实例内 `huggingface` 通常受限（见 §6） |

> **许可合规（重要）**：MiniMax H3 社区许可**不适用于美国 / 欧盟 / 英国 / 韩国**用户。中国个人非商业使用无碍。脚本默认自动接受 License 并记入日志（可用 `--no-accept-license` 关闭，但非交互模式会拒绝安装 `E403`）。

## 3. 一键部署

### 3.1 魔搭 Notebook（首选）

魔搭持久化目录 `/mnt/workspace`（100GB，关机保留）。新开实例无需重装——资产已落盘，**同一条命令自动判定「已安装」并直接启动**（见 §9）。

**方式 A · 手动上传 / git 克隆（当前可用）**
```bash
# 在 Web IDE 终端：
cd /mnt/workspace
git clone <脚本仓库地址> veda-setup        # 或直接把 veda-setup/ 目录上传到 /mnt/workspace
bash /mnt/workspace/veda-setup/install.sh
```

**方式 B · 一键 bootstrap（待托管地址）**
> 脚本需要一个稳定的托管地址来提供 `bootstrap.sh`（GitHub / GitLab / 魔搭 / OSS）。当前在本地开发阶段，可先用以「方式 A」交付；托管地址确定后填此处即可：
```bash
curl -fsSL https://<稳定托管地址>/bootstrap.sh | bash
# 之后每次新开实例，只需：
bash /mnt/workspace/veda-setup/install.sh   # 资产已持久化，分钟级恢复
```

安装完成后 ComfyUI 在**后台启动**，终端立即返回并给出访问地址（Web IDE 端口预览 / 隧道，默认 `127.0.0.1:8188`）。

### 3.2 Windows 本地
双击 `install.bat`（或 `python setup_veda.py`）。无 Python 时按提示 `winget install Python.Python.3.12` 后重跑。结束后自动尝试打开浏览器。

### 3.3 macOS（实验性，Apple Silicon）
```bash
bash install.sh   # 走 MLX 后端，模型权重以 ComfyUI 官方支持为准
```

## 4. 安装根目录

脚本按以下优先级确定安装根（`<root>`）：

1. `--install-root PATH`
2. 环境变量 `COMFYUI_INSTALL_ROOT`
3. 检测到 `/mnt/workspace` → `/mnt/workspace/comfyui-veda`
4. Windows → `<脚本目录>/ComfyUI`
5. 其他 → `~/comfyui-veda`

部署后目录结构（魔搭示例）：
```
/mnt/workspace/comfyui-veda/
├── ComfyUI/                      # ComfyUI 本体（锁定 commit）
│   ├── custom_nodes/
│   │   └── Veda-on-ComfyUI/      # Veda 加速节点（锁定 commit）
│   ├── models/                   # 模型权重（predictors / diffusion_models / ...）
│   └── user/default/workflows/   # 已拷贝的 Veda 官方模板
├── venv/                        # Python 虚拟环境（魔搭复用镜像 torch）
├── run/                         # start.sh / stop.sh / status.sh / comfyui.log
├── logs/                        # JSONL 结构化日志 + 诊断包
├── .setup.lock                  # 并发锁（含 stale 自动释放）
└── .setup-state.json            # 幂等状态（跨实例恢复依据）
```

## 5. 档位（Profile）

`--profile` 可选：`minimal` / `standard` / `full` / `lowvram` / `auto`（默认）。

`-auto` 按**实测显存**自动选档：
- VRAM < 16GB → `lowvram`（需 `--accept-third-party`）
- 16–24GB → `standard`（A10 24GB 默认档）
- > 24GB → `full`

| 档位 | 模型 | 显存下限 | 说明 | 模型体积（约） |
|---|---|---|---|---|
| `minimal` | 否（`--skip-models` 生效） | 12GB | 仅 Veda 节点 + T2VA 预测器，不下主模型 | 0.26GB |
| `standard` | 是 | 16GB | int8 DiT + 32B nvfp4 编码器（A10 适配） | **~42GB** 模型 |
| `full` | 是 | 24GB | 最高画质权重（含 R2VA 预测器） | ~42GB + 0.26GB |
| `lowvram` | 是 | 8GB | 第三方量化权重 | 需 `--accept-third-party` |

> 磁盘预算：默认按 **稳定占用**（模型 + ComfyUI ~3GB + venv <1GB ≈ 46GB）校验；若持久盘不足会自动降档（`standard → lowvram`）。魔搭环境下载缓存默认重定向到本地盘 `/root/.cache`，避免缓存与模型在持久盘叠加导致峰值爆盘。

## 6. 下载源链（自动适配，无需手动干预）

脚本在 P0 预检阶段探测 egress，自动选择源链：

- **魔搭实例内**：`modelscope → github(gh-proxy.com / ghproxy.net / gitclone.com) → codeload(tarball 兜底)`；**自动排除 `hf-mirror` / `huggingface`**（魔搭外网通常受限）。模型权重主源为 `modelscope` CLI；若 `gh-proxy` 可达，best-effort 尝试经 `gh-proxy` 代理的 HF 作为补充。
- **通用环境**：`modelscope → hf-mirror → huggingface`。

GitHub 类源（ComfyUI 本体 / Veda 节点）统一走可达代理，多候选依次探测，`--depth`/tarball 自动降级。完整策略见设计文档 §9。

## 7. 常用参数

| 参数 | 说明 | 默认 |
|---|---|---|
| `--install-root PATH` | 安装根目录 | 自动探测（见 §4） |
| `--mode NAME` | 运行模式：`auto`=自动判定（已安装仅启动 / 未安装安装+启动）；`install`=强制进入安装段（幂等增量，仅补缺失项）；`launch`=强制仅启动（安装不完整报 E701） | `auto` |
| `--only pN[,pN]` | **单环节执行**（v2.3.7）：仅跑指定环节，如 `--only p5`（补模型下载）、`--only p1,p3`（重装 ComfyUI+节点）、`--only p7`（重新验收）；P0 预检始终前置；`install_completed` 不变更；未含 `p8` 则不启动 | 无（全流程） |
| `--profile NAME` | `minimal`/`standard`/`full`/`lowvram`/`auto` | `auto`（按实测 VRAM 选） |
| `--source-priority LIST` | 下载源优先级（覆盖自动探测）；当前仍以 `auto` 自适应为主 | `auto` |
| `--skip-models` | 只搭环境不下模型 | false |
| `--keep-cache` | 下载后保留模型缓存（默认清理省磁盘） | false |
| `--listen` | 绑定 `0.0.0.0`（默认 `127.0.0.1`） | false |
| `--accept-third-party` | 允许下载社区第三方量化权重（`lowvram` 档需要） | false |
| `--no-accept-license` | 关闭自动接受 License（非交互模式将拒绝 E403） | false（即默认自动接受） |
| `--interactive` | 退回人工确认模式 | false |
| `--local-code` | 代码+venv 放本地盘（**魔搭强制 OFF**，仅 T2/T3 可选） | false |
| `--dry-run` | 只打印动作不落盘（生成预检与恢复计划） | false |
| `--resume` | 显式续跑（等价于幂等重跑，已完成资产跳过） | false |
| `--deep-verify` | 资产全量哈希校验（默认仅大小+头部） | false |
| `--smoke-test` | 无头启动探测 `/object_info`（首跑豁免全模型加载） | false |
| `--no-launch` | 装完不启动 ComfyUI | false |
| `--doctor` | 只生成诊断包后退出 | false |
| `--log-dir PATH` | 日志目录（默认 `<root>/logs`） | 自动 |
| `--force` | 覆盖外来 ComfyUI 检测（E601） | false |

完整参数见 `python setup_veda.py --help`。

## 8. 可视化使用（出片）

1. 安装完成，访问 `http://127.0.0.1:8188`（魔搭经 Web IDE 端口预览 / 隧道）。
2. 菜单 **Workflow → Browse Templates → Veda-on-ComfyUI**，选 **Veda MiniMax H3 T2VA**（文生视频）或 **Veda MiniMax H3 R2VA**（图生视频）。
3. 填入提示词，Queue Prompt 出片。

> 模板由脚本在 P6 阶段从 Veda 节点自带的 `example_workflows/` 拷贝到 `user/default/workflows/`，无需手动下载外部模板。

## 9. 日常使用（重开实例 / 恢复）

**安装 / 启动自动分流（`--mode auto`，默认）**：每次运行时读取 `.setup-state.json` 的 `install_completed` 标志并检查关键目录，自动决定走哪条路径——

- **持久盘尚无安装（首次）**：自动执行安装段（P1–P7）+ 启动（P8）；
- **已安装（含重开实例，挂载同一 `/mnt/workspace`）**：自动**仅启动**——跳过 P1–P7 安装段，不重下模型、不重建 venv，秒级进入 ComfyUI；
- **已安装但 venv 失效**（如新实例镜像 Python 版本变化）：轻量预检失败后自动降级转安装段，仅重建 venv（模型零重下），随后照常启动；
- 每次运行日志会打印 `MODE_DECISION`（`install` / `launch-only`），据此确认当前路径。

```bash
# 新开魔搭实例：同一条命令，自动判定（已安装 → 直接启动）
bash /mnt/workspace/veda-setup/install.sh

# 显式控制：
python setup_veda.py --mode install   # 强制进入安装段（幂等增量，仅补缺失项）
python setup_veda.py --mode launch    # 强制仅启动（未完成安装报 E701）
```

**单环节执行（`--only`，v2.3.7）**——安装中断后只想补某个环节、或单独重装某一步时使用：

```bash
python setup_veda.py --only p5        # 只补模型下载（P4/P5 资产按 state 幂等续传）
python setup_veda.py --only p1,p3     # 只重装/对齐 ComfyUI + Veda 节点
python setup_veda.py --only p7        # 只重新验收
python setup_veda.py --only p6,p8     # 模板 + 启动
```

说明：P0 预检始终前置（提供环境/档位/网络上下文）；`install_completed` 标志不变更（部分执行不构成完整安装）；不含 `p8` 时不会启动 ComfyUI；环节号非法（如 `p9`）直接报参数错误退出。

**重试快速跳过（v2.3.7）**：安装失败后直接重跑同一命令即可——除既有的 per-asset 幂等跳过外，P1/P3 现在按「git HEAD == 锁定 commit」判定：已对齐则零网络操作直接跳过（不再重复 fetch / 重装节点依赖），重试只补真正缺失的环节。日志对应输出 `P1/skip`、`P3/veda 跳过获取`、`P3/req 标记匹配跳过`。

- **启停 ComfyUI**（安装后，可脱离本脚本独立使用）：
  ```bash
  bash run/start.sh      # 后台启动（nohup，写 pid）
  bash run/status.sh     # 健康检查
  bash run/stop.sh       # 停止
  ```
  Windows 对应 `run/start.bat` / `stop.bat` / `status.bat`。
- **查看日志**：`<root>/logs/setup_YYYYMMDD_HHMMSS.jsonl`（结构化，便于排错）。

## 10. 常见问题速查

- 想要更快恢复 / 跳过模型下载：`--skip-models`（搭环境）、`--profile minimal`。
- 误用 `--mode launch` 报 E701：说明安装未完成，去掉该参数（默认 auto 会自动安装+启动）或改用 `--mode install`。
- 显存小 / 想跑低显存档：显存不足时脚本自动降档；或显式 `--profile lowvram --accept-third-party`。
- 想看脚本会做什么而不落盘：`--dry-run`。
- 出错了：先跑 `python setup_veda.py --doctor` 拿诊断包，再查 [问题排错](问题排错.md)。

## 11. 已知限制 / 待实测

脚本逻辑与可复现性已就绪，以下为**运行时探测项**（设计已做自适应兜底，不依赖预设结论），仍建议在真实魔搭实例上验证：

- **G4** `modelscope download --local_dir` 在 `/mnt/workspace` 是否复制缓存（影响缓存预算）；
- **G5** 魔搭内 `gh-proxy.com` / `gitclone.com` 是否可达（影响 GitHub 兜底）；
- **G6** A10 24GB 实测能否跑 `standard` 档（决定默认档位）；
- **G7** 魔搭本地盘（`/root`）容量是否 ≥ 最大模型体积（决定缓存重定向策略）。
